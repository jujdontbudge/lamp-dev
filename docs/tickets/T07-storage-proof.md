# Durable capture and storage

## Goal
Implement durable disk and memory capture, restore and suspend/resume on ordinary ext4 and supported XFS-reflink and btrfs storage. Acknowledged durable state survives recovery; forks have independent writes and consistent generations; live ancestors are retained; unauthorized capture producers are rejected. Local durable fork works without reformatting the owner's disk (architecture §§6–7). People rely on this state to return to unfinished work and keep their data.
