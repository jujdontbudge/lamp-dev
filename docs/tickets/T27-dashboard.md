# Dashboard

## Goal
Give the owner one live page that shows everything their fleet is doing. When this is done, the dashboard served by any host shows, live, every host, sandbox, session, task and resource the viewer is allowed to see (OPS-001), including setup progress and failures, both countdowns (idle and task budget), sharing, approvals that show the actual requested effect, private browser takeover, budgets and audit, saved state stranded on a sleeping host, and actual feature availability and useful operational errors. Done, stuck and needs-decision events reach the configured notification sinks with inspectable retries, acknowledgement and private signed-in action links (OPS-003).

Every requirement in the spec has a "what you'd see" part, and this is where a person sees it. In journey 1 Alice sees when setup is finished, watches the work and answers when it needs her; in journey 5 she sees the real effect of an action before approving it.
