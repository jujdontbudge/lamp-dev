# Fleet

## Goal
Make several hosts behave as one Lamp: one address, one key namespace, automatic placement and strict host pinning. When a host sleeps or disconnects, an awake host can start permitted work using capacity already reserved for it. Callers see when saved files and sessions remain unavailable on the sleeping host. Retries do not duplicate effects, writers are fenced, quotas and approvals cannot be spent twice, and stale keys or backups do not revive authority (HST-002–004). This lets people keep working across their own machines without extra infrastructure.
