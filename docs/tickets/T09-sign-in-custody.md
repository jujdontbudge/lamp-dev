# Subscription sign-in custody

## Goal
Keep a person's subscription sign-in working in their own trusted sandboxes. Official Claude Code and Codex harnesses retain approved sign-in and refresh through same-owner memory fork and suspend/resume. The login-bearing sandbox reaches only its vendor's endpoints; general builds, downloads and git run in a separate token-free sandbox. Templates, exports beyond custody and sharing reconstruct nonsecret inputs and start the harness fresh, carrying no subscription credentials (CRED-003, CRED-004; ADR 0004). Ready sign-in must preserve the person's custody of their account.
